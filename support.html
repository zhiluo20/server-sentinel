Frequently asked questions

What if ServerSentinel says no private key is imported?

Open Settings, select the server, and import the key under Authentication. The key is stored in the device Keychain. Password authentication is also available.

Are passphrase-protected private keys supported?

Not currently. The app supports unencrypted OpenSSH Ed25519 and ECDSA keys (P-256/384/521), plus PKCS#8 PEM ECDSA. Convert unsupported keys with ssh-keygen or use password authentication.

Why is SystemSSH unavailable on iPhone?

SystemSSH invokes the macOS system SSH executable. On iPhone and iPad, use DirectSSH, enter an IP address or domain directly, and provide the server's OpenSSH host public key.

Does monitoring continue in the background?

No. Polling runs while the app is in the foreground. Backgrounding stops polling and closes terminal sessions; returning to the foreground starts a fresh collection.

Where are credentials stored?

Passwords, private keys, and Agent read tokens are stored in the local device Keychain. ServerSentinel has no developer backend and does not upload them.
